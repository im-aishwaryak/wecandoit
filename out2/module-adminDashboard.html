Module: adminDashboard

Administrator dashboard functionality. This module loads and displays administrative dashboard data from Firebase Firestore. It manages item approvals, retrieval requests, and item status updates. Features: - Loads items based on status categories - Displays dashboard cards dynamically - Allows administrators to approve items - Marks items as retrieved - Updates Firestore records
