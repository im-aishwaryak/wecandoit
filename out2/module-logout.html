Module: logout

Handles user logout functionality. This module manages user sign-out from Firebase Authentication. It also clears locally stored session data and redirects the user to the login page after successful logout. Features: - Firebase sign-out handling - Local storage cleanup - Safe event listener attachment - Error handling for failed logout attempts
