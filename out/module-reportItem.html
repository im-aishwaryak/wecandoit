Module: reportItem

Handles submission of new lost/found item reports. This module allows authenticated users to submit item reports to Firestore, including item details, images, and verification questions. Images are uploaded to Cloudinary before being stored in the database. Features: - Form validation via Firebase auth state - Image upload to Cloudinary - Dynamic verification question storage - Firestore document creation - Submission status tracking
