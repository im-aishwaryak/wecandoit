scripts/student_dashboard.js

Handles loading and rendering of student dashboard data. This script: - Listens for Firebase authentication state changes - Loads student-specific dashboard data - Creates dashboard item cards dynamically - Formats date information - Populates modal windows for item details Dashboard Sections: - Ready to Claim Items - Pending Retrieval Requests - Pending Submissions - Retrieved Items History
