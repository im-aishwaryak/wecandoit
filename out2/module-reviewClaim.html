Module: reviewClaim

Handles administrator review of item retrieval claims. This module allows administrators to: - Load item and claim data from Firestore - Compare verification answers - Approve or reject retrieval claims - Update item and claim status accordingly The comparison view displays both: - Original item submission details - Student retrieval request details
