Module: firebaseModule

Firebase configuration and utility module. This module initializes Firebase services and exports commonly used Firebase instances and helper functions. It provides access to authentication, Firestore database, and cloud storage functionality used throughout the application. Services Initialized: - Firebase App - Firebase Authentication - Cloud Firestore - Firebase Storage Exported Features: - Authentication methods - Firestore database operations - Storage upload utilities - Item retrieval helper functions
