Module: claimItem

Item claim submission functionality. This module allows users to submit a claim request for a found item. It retrieves item data from Firebase, dynamically displays verification questions, validates user input, and submits claim information to Firestore. Features: - Loads selected item details - Displays verification questions dynamically - Validates user identity and answers - Submits claim requests - Updates item and user records
